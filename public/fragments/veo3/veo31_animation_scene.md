# Creative Animation Scene Template (Veo 3.1)

## Scene Type Characteristics
- Stylized visuals (non-photorealistic)
- Imaginative/fantastical subjects
- Artistic direction emphasized over realism
- Creative freedom with physics and logic
- Style keywords are primary descriptors

## Optimal Prompt Structure

```
[Style descriptor] of [fantastical subject] [action] [imaginative environment].
[Additional creative details].
```

## Style Keywords (Define the Look)

**Animation Styles**:
- Stop-motion animation, claymation
- 3D cartoon style, Pixar-style animation
- Paper cut-out animation, collage style
- Rotoscope style, cel-shaded animation
- Hand-drawn 2D animation, anime style

**Aesthetic Descriptors**:
- Whimsical, surreal, fantastical, dreamlike
- Playful, vibrant, colorful, pastel
- Geometric, abstract, stylized
- Cute, charming, quirky, eccentric

**Artistic References**:
- Tim Burton-esque, Studio Ghibli-inspired
- Wes Anderson aesthetic, Dr. Seuss-like
- Minimalist, maximalist, art deco

## Creative Subject Ideas

**Fantastical Characters**:
- Tiny robots, magical creatures, anthropomorphic objects
- Mythical beings, imaginary animals, sentient plants
- Living toys, miniature worlds, parallel universes

**Imaginative Environments**:
- Miniature planets, floating islands, impossible architecture
- Candy landscapes, bioluminescent forests, crystal caves
- Dreamscapes, abstract dimensions, surreal spaces

## Optimal Length
**100-200 words** - Style-heavy, concept-focused

## Official Example (from Google Docs)

```
A whimsical stop-motion animation of a tiny robot tending to a garden of glowing
mushrooms on a miniature planet.
```

## Advanced Examples

**Example 1 - Stop-Motion**:
```
Charming stop-motion animation in the style of Aardman. A clay-molded badger detective
with a magnifying glass examines tiny footprints in a miniature forest made entirely
of felt and wire. The badger's expressive eyes widen as he discovers a glowing acorn.
Whimsical orchestral music plays as fireflies (made from LEDs) twinkle around him.
```

**Example 2 - 3D Cartoon**:
```
Vibrant 3D cartoon animation in a Pixar-esque style. An excitable slime creature with
googly eyes bounces through a candy-colored laboratory, accidentally creating rainbow
explosions with each bounce. Playful sound effects (boings, pops, sparkles) accompany
each movement. The slime giggles with childlike joy.
```

**Example 3 - Paper Cut-Out**:
```
Layered paper cut-out animation with geometric shapes and bold colors. A paper bird
made of origami unfolds its wings and soars through a flat, 2D world of collaged
landscapes. Minimalist ambient sounds (soft rustling, gentle whoosh) create a meditative
atmosphere.
```

## Key Success Factors
1. Strong style descriptor (stop-motion, 3D cartoon, etc.)
2. Fantastical or imaginative subject
3. Creative environment that matches the style
4. Focus on aesthetic over realism
5. Audio design that enhances whimsical tone
6. Concise but evocative language
