**CHARACTER CONSISTENCY ACROSS GENERATIONS**

**Key Insight:** Veo 3 maintains visual continuity when character descriptions are detailed and consistent.

**Best Practices:**

**1. Create Detailed Character Descriptions**
Be highly specific about:
- **Physical features:** "woman in her early 30s, shoulder-length curly black hair, brown eyes, oval face"
- **Clothing:** "wearing a navy blue blazer over white shirt, dark jeans, brown leather boots"
- **Distinguishing marks:** "small scar above left eyebrow, silver hoop earrings, subtle freckles"
- **Body type/build:** "athletic build, approximately 5'8\", confident posture"

**2. Maintain Exact Descriptions**
- Save your character descriptions as reusable templates
- Copy/paste the EXACT description across multiple prompts
- The more unique and specific, the better Veo maintains consistency
- Generic descriptions ("a man", "a woman") produce different characters each time

**3. Scene-Specific Details**
While keeping core character description identical, you can vary:
- Expressions: "smiling warmly" vs "looking concerned"
- Actions: "walking briskly" vs "standing still, arms crossed"
- Context: Different locations, lighting, camera angles

**Example Consistent Character Template:**

```
CHARACTER: Woman, late 20s, straight blonde hair to mid-back, blue-gray eyes, fair skin with light freckles across nose, wearing round gold-rimmed glasses, subtle smile lines, dressed in charcoal turtleneck sweater and black high-waisted trousers.

SCENE 1: [Character description above], walking through autumn park, leaves crunching underfoot, golden hour lighting.

SCENE 2: [Character description above], sitting at cafe window, sipping coffee, rain streaking the glass outside.

SCENE 3: [Character description above], standing on city rooftop at sunset, wind blowing hair gently.
```

**Tips:**
- Store character descriptions in your prompt library for reuse
- More detail = better consistency (aim for 30-50 words per character)
- Test consistency by generating 2-3 clips with same description
- If consistency breaks, add MORE specific details (tattoos, jewelry, unique clothing)
